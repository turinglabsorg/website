# turinglabs website

Personal portfolio website for [turinglabs](https://github.com/turinglabsorg), built with React and styled with [terminal.css](https://terminalcss.xyz/) for a retro terminal look.

## Getting Started

### Prerequisites

- Node.js
- Yarn

### Install Dependencies

```bash
yarn install
```

### Run Locally

```bash
yarn start
```

Opens the app at [http://localhost:3000](http://localhost:3000).

### Build for Production

```bash
yarn build
```

Outputs optimized static files to the `build/` directory.

## Tech Stack

- [React](https://reactjs.org/) (Create React App)
- [terminal.css](https://terminalcss.xyz/)

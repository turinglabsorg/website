# turinglabs website

Personal website for [turinglabs](https://turinglabs.org), built with React and styled with [terminal.css](https://terminalcss.xyz/) for a retro terminal look.

## Prerequisites

- [Node.js](https://nodejs.org/) (v14 or later recommended)
- [Yarn](https://yarnpkg.com/)

## Getting Started

Install dependencies:

```bash
yarn install
```

Start the development server:

```bash
yarn start
```

The app will be available at [http://localhost:3000](http://localhost:3000).

## Building for Production

```bash
yarn build
```

This outputs optimized static files to the `build/` directory, ready to be deployed.

## Project Structure

```
public/       Static assets (images, favicon, index.html)
src/
  App.jsx     Main application component
  App.css     Custom styles
  index.jsx   Entry point
```
